1. What is a function?

A function is a named block of code that does one job. You write it once with def, then call it as many times as you like.

def add(a, b):      # a and b are parameters (inputs)
    return a + b    # return sends the answer back

result = add(2, 3)   # 2 and 3 are arguments
print(result)         # 5

Parameters are the inputs a function needs. Return is the output it hands back. Think of a machine: put something in, get something out.

print vs return. print only shows text on screen. return gives a value back so other code can use it. Functions that calculate should return. Only the report function should print.

The rules of good functions: one job each, a name that says what it does (calculate_average, not func1), data goes in through parameters, results come out through return.

2. What is wrong with your current program?

Nothing breaks on the happy path, but look closer:

  • Everything is at the top level. You cannot reuse the average calculation in another program without copying and pasting.
  • Each part has no name. A reader must read every line to learn what a block does.
  • Two real bugs are hiding in it. Spot them in the quiz below.
The idea behind refactoring: keep behaviour the same, but split the code into small named pieces. This is called DRY: Don’t Repeat Yourself.

3. Your program, refactored

Each block of your script becomes one function. Read each one and match it to the part of your original code.

def get_marks():
    """Ask for marks until the user types x. Return a list."""
    marks = []
    text = input("Enter a mark (0-100) or x to finish: ")
    while text != "x":
        if text.isdigit() and int(text) <= 100:
            marks.append(int(text))
        else:
            print("Invalid mark.")
        text = input("Enter a mark (0-100) or x to finish: ")
    return marks

def calculate_average(marks):
    total = 0
    for m in marks:
        total = total + m
    return total / len(marks)

def find_highest(marks):
    highest = marks[0]
    for m in marks:
        if m > highest:
            highest = m
    return highest

def find_lowest(marks):
    lowest = marks[0]
    for m in marks:
        if m < lowest:
            lowest = m
    return lowest

def get_band(mark):
    """Turn ONE mark into its band name."""
    if mark >= 80:  return "Outstanding"
    elif mark >= 70: return "Highly competent"
    elif mark >= 50: return "Competent"
    elif mark >= 40: return "Not yet competent"
    else:           return "Not achieved"

def count_bands(marks):
    bands = {"Outstanding": 0, "Highly competent": 0,
             "Competent": 0, "Not yet competent": 0,
             "Not achieved": 0}
    for m in marks:
        bands[get_band(m)] += 1
    return bands

def percent_competent(bands, total_learners):
    not_competent = bands["Not yet competent"] + bands["Not achieved"]
    return (total_learners - not_competent) / total_learners * 100

def print_report(marks):
    bands = count_bands(marks)
    print("===== CLASS MARKS REPORT =====")
    print(f"Learners : {len(marks)}")
    print(f"Average  : {calculate_average(marks):.1f}")
    print(f"Highest  : {find_highest(marks)}")
    print(f"Lowest   : {find_lowest(marks)}")
    print("-" * 30)
    for name, count in bands.items():
        print(f"{name:<18}{count:>3}")
    print("-" * 30)
    print(f"Competent or better: {percent_competent(bands, len(marks)):.0f}%")

def main():
    marks = get_marks()
    if len(marks) == 0:
        print("No marks.")
    else:
        print_report(marks)

main()
Look at main(). The whole program now reads like a sentence: get the marks, and if there are some, print the report. You can also reuse get_band(75) or calculate_average([60, 70]) anywhere else.

Notice get_band: your original had a long if/elif chain inside a loop. Pulling it out gives you a tiny function that is easy to test on its own.
